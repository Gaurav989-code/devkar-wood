We don’t need a public customer account model.

The Order model will contain guest information:

customer: {
  name,
  email,
  phone,
  alternativePhone
}

And shipping details:

shippingAddress: {
  addressLine,
  landmark,
  city,
  state,
  postalCode
}
Cart storage

Before checkout, the cart will be stored in:

Redux Toolkit + localStorage

This means the customer’s cart remains available after refreshing or reopening the website on the same device.

After successful checkout, the backend creates a permanent MongoDB order.

Customer order tracking

Because there is no customer account, customers can track an order using:

Order number + mobile number

For example:

Order number: DWC-20260906-1042
Mobile number: 9876543210

The API returns only safe order information after both values match.

Admin authentication

Admin login is still necessary.

The admin flow will be:

Admin login
    ↓
Secure JWT cookie
    ↓
Protected admin dashboard
    ↓
Manage products and orders

Regular customers will never see this login.
